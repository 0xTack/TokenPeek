01 / Traceability

信息溯源，不只是给一个链接

一条新闻从哪来、谁先报、后来怎么变，应该能一眼看到。 Under the Sun 保留来源、时间和原文，并把同一话题的后续报道串成时间线。

  • 来源不合并。不同平台的报道分别列出，能看到是谁先发、谁跟进。
  • 时间不丢。有发布时间就用发布时间，没有就标明抓取时间。
  • 原文可回。每条都保留原文链接，AI 解读不替代材料。
  • 话题可回溯。勾选跟踪后，自动在本地历史里找更早的报道，补到时间线最前面。

AI 只做解读，不参与排序；排序只看平台热度、跨源数量和新鲜度。

02 / Bound volume

每天一份报纸，最后成为一本合订本

不是信息流，是报纸。每天生成一份按日期命名的日报，读完就归档； 想翻回某一天，打开那一天的合订本即可。

按日期装订

日报按 YYYY-MM-DD 命名，天然形成时间顺序。今天的报纸、上周的报纸、上个月的报纸，都在同一个目录里。

版面固定

头条、要闻、简讯三档，国内红、国外蓝、简讯灰。每天的结构一致，翻起来像同一份报纸，而不是随机卡片。

状态留在纸上

已读、跟踪、AI 解读都写回当天的 Markdown。换设备、换电脑，打开还是那一页。

手机也能读

日报和跟踪笔记同步到手机，阅读、AI 交流、停止/重新追踪、时间线排序都能直接用；抓取仍在电脑端完成。

03 / Features

不是又一个 RSS 阅读器

01

多源汇总

热榜、RSS、新闻站点统一抓取，补全正文后再进入报纸。

02

去重与聚类

同一件事的多个来源合并成一组，避免整版都是同一条新闻。

03

AI 判断式解读

不是问答框。它按固定方法拆解事实、信源、矛盾、利益、反方与可证伪条件。

04

跟踪时间线

勾选跟踪后，后续报道自动进入时间线，并能回溯到最早来源。

05

本地优先

日报、跟踪、判断都写在 vault 的 Markdown 里，不锁进数据库。

06

AI 可选，不替你裁决

用自己的 API Key；AI 只给出可检验的解读，不参与排序，最终判断由你确认。

AI / Method

AI 不是问答框，是一套判断流程

它不替你下结论，而是把材料拆到可以检验。

01

事实 / 推断 / 判断分层

只把材料中能确定的部分写成事实；推断和判断分开写，信息不足时明确标注「尚不清楚」。

02

信源与报道质量

看信源是否单一、是否缺关键背景、标题是否夸大，而不是只看措辞是否激烈。

03

核心矛盾与利益

找出真正的冲突：谁获利、谁承担成本、谁有决定权、谁没有发言权。

04

反方与可证伪条件

给出反对这个判断的最强理由，以及什么新事实能推翻它，而不是只给一个结论。

05

判断卡与证据

把判断写成可复核的 claim、确认条件、反证条件和置信度；后续证据自动标为支持、反驳或无关。

06

AI 不参与排序

排序只看平台热度、跨源数量和新鲜度；AI 负责拆解材料，不负责决定哪条新闻更重要。

05 / Install

安装

完整模式（macOS，可选）

  1. 在 Obsidian 第三方插件里搜索 Under the Sun，安装并启用。
  2. 下载本地增强服务，解压后双击 install-backend.command。
  3. 安装器会装好 Python 依赖、token 和后台服务。
  4. 重启 Obsidian，插件会自动连接。

下载本地增强服务 SHA-256

只装增强服务，不覆盖插件。需要 Python 3.9+；定时任务由 launchd 负责。

开源可审计 · 本地优先 · 无遥测 · 查看源码

06 / FAQ

常见问题

数据存在哪里？

日报、跟踪笔记都在 vault 的 Markdown 里；本地增强服务数据库和抓取缓存在本机，不会上传。

AI 会替我做判断吗？

不会。AI 按固定流程拆解材料：事实/推断/判断分层、信源质量、核心矛盾、利益与权力、反方与可证伪条件。它给出的是可检验的解读，排序仍按来源、热度和时间，最终判断由你确认。

手机上能抓取吗？

没有本地增强服务时，手机只负责阅读和 AI；轻量模式可以直接在插件内刷新 RSS。完整模式的抓取在电脑端增强服务完成。

轻量模式和完整模式能同时开吗？

它们是同一个插件的两种模式，不存在“同时装两个”。本地增强服务连上就是完整模式，连不上就是轻量模式。

Windows 可以用吗？

完整模式目前只提供 macOS 本地增强服务。Windows / Linux 先用轻量模式，或手动运行 Python 增强服务。

为什么强调「合订本」？

因为新闻不是刷完就消失的信息流。按日期归档、能回看、能对照，才是一份可以长期使用的资料。
