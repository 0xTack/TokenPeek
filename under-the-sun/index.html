01 / Traceability

信息溯源，不只是给一个链接

一条新闻从哪来、谁先报、后来怎么变，应该能一眼看到。 Under the Sun 保留来源、时间和原文，并把同一话题的后续报道串成时间线。

  • 来源不合并。不同平台的报道分别列出，能看到是谁先发、谁跟进。
  • 时间不丢。有发布时间就用发布时间，没有就标明抓取时间。
  • 原文可回。每条都保留原文链接，AI 解读不替代材料。
  • 话题可回溯。勾选跟踪后，自动在本地历史里找更早的报道，补到时间线最前面。

AI 只做解读，不参与排序；排序只看平台热度、跨源数量和新鲜度。

02 / Bound volume

每天一份报纸，最后成为一本合订本

不是信息流，是报纸。每天生成一份按日期命名的日报，读完就归档； 想翻回某一天，打开那一天的合订本即可。

按日期装订

日报按 YYYY-MM-DD 命名，天然形成时间顺序。今天的报纸、上周的报纸、上个月的报纸，都在同一个目录里。

版面固定

头条、要闻、简讯三档，国内红、国外蓝、简讯灰。每天的结构一致，翻起来像同一份报纸，而不是随机卡片。

状态留在纸上

已读、跟踪、AI 解读都写回当天的 Markdown。换设备、换电脑，打开还是那一页。

手机也能读

日报和跟踪笔记同步到手机，阅读、AI 交流、停止/重新追踪、时间线排序都能直接用；抓取仍在电脑端完成。

03 / Features

不是又一个 RSS 阅读器

01

多源汇总

热榜、RSS、新闻站点统一抓取，补全正文后再进入报纸。

02

去重与聚类

同一件事的多个来源合并成一组，避免整版都是同一条新闻。

03

AI 深度解读

事实、报道评价、核心矛盾、反方与判断，明确区分材料与推断。

04

跟踪时间线

勾选跟踪后，后续报道自动进入时间线，并能回溯到最早来源。

05

本地优先

日报、跟踪、判断都写在 vault 的 Markdown 里，不锁进数据库。

06

AI 可选

用自己的 API Key；不开启 AI 也能正常读报、跟踪和归档。

05 / Install

安装

完整版（仅 macOS）

  1. 下载最新 Release 压缩包（macOS）。
  2. 解压到 ~/code 这类非受保护目录。
  3. 双击 install.command，按提示完成安装。
  4. 重启 Obsidian，打开「朝闻天下」主页。

下载完整版（macOS） SHA-256

仅支持 macOS。需要 Python 3；定时抓取由 launchd 负责。

社区版

  1. 在 Obsidian 第三方插件里搜索 Under the Sun。
  2. 安装并启用。
  3. 在设置里填 RSS 地址和 AI Key。
  4. 回到主页点「刷新 RSS」。

下载社区版（手动安装） SHA-256

不需要 Python；Windows / macOS / Linux / 手机都能用。源码：0xTack/obsidian-under-the-sun

06 / FAQ

常见问题

数据存在哪里？

日报、跟踪笔记都在 vault 的 Markdown 里；完整版的数据库和抓取缓存在本机项目目录，不会上传。

AI 会替我做判断吗？

不会。AI 负责整理材料、给出可检验的解读；排序和取舍仍按来源、热度和时间，不交给模型。

手机上能抓取吗？

完整版不能，手机只负责阅读和 AI；社区版用 RSS，可以在插件内刷新。

社区版和完整版能同时装吗？

建议不要。两个插件会写入不同目录，但同时启用容易混淆。选一个使用即可。

Windows 可以用吗？

完整版目前只支持 macOS。Windows 和其他系统请用社区版：纯 Obsidian 插件，RSS + AI，不需要 Python。

为什么强调「合订本」？

因为新闻不是刷完就消失的信息流。按日期归档、能回看、能对照，才是一份可以长期使用的资料。
