## 1.6 改了什么

### 通用订阅监控（新功能）
- 设置 →「订阅与花费」：可添加任意订阅，只要接口返回 JSON
- 认证：不需要 / Bearer / 自定义 Header
- 指标类型：已用 % / 剩余 % / 剩余÷总量
- 字段路径按点分层级（`usage.rolling.percent`），数组用下标（`data.0.left`）
- 「识别字段」按钮：请求一次接口，把所有数字字段列成下拉菜单直接选
- 面板显示两种样式：**胶囊** / **柱状图**（横向），设置里切换
- 口径切换：**剩余 / 已使用**，颜色规则随之反转（剩余 ≤30% 橙、≤10% 红；已使用 ≥70% 橙、≥90% 红）
- 数据文件：`~/Library/Application Support/DeepSeekCost/subscriptions.json`（600）

### 面板
- 订阅行和余额行合成一块，中间无分割线
- 整个区块只有一个刷新按钮，同时刷新余额和订阅
- 「充值」不再常驻，鼠标移到余额行才浮出（overlay，不改变行高）
- 订阅区块设了最小高度，数据到达时面板不再上下伸缩

### 设置
- 合并为「订阅与花费」，订阅和手动花费放一起
- 删除：用量显示切换、更新日志 / 反馈入口
- 「我的用量」固定逐行数字显示

### 修复
- 显示切换不生效：原因是 `@AppStorage` 跨窗口刷新不可靠，改成共享的 `SubscriptionSettings`（ObservableObject）

## 发布流程（这次实际用的）

```bash
cd "/Users/xa/Documents/Default Project/DeepSeekCost"
git add -A && git commit -m "..." && git push origin main
git tag -f v1.6 && git push -f origin v1.6

./package.sh            # 自动把 1.5 → 1.6、Build 6 → 7
./package-intel13.sh    # 沿用 Info.plist 版本

gh release create v1.6 dist/TokenPeek-1.6-AppleSilicon.dmg ... \
  --title "TokenPeek 1.6" --notes-file /tmp/notes-1.6.md
gh release upload v1.6 windows/dist/DeepSeekDashboard-1.3-Windows-x64.zip

cd site
./publish.sh --version 1.6 --mac-version 1.6 --windows-version 1.3 \
  --base "https://github.com/0xTack/TokenPeek/releases/download/v1.6/" \
  --notes-file /tmp/notes-1.6.md
```

注意：`publish.sh --notes-file` 会把整个文件当条目塞进更新日志，下载说明也进去了，发完要手工删掉多余条目（这次已修）。
