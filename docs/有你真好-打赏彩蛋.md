# 「有你真好」打赏彩蛋 · 复刻说明

> 注意：App 现在已改为「爱发电按钮 + 可选微信赞赏码」双入口，最新完整说明见 [打赏功能说明.md](打赏功能说明.md)。本文保留旧版二维码彩蛋的复刻细节。

这是一个不依赖支付回调的赞赏页彩蛋：打开赞赏页后自动出现吹捧文案、玻璃条和欢呼音效，不挡二维码，也不要求用户点按钮。

完整可复制代码：[DonationEasterEgg.swift](DonationEasterEgg.swift)

---

## 1. 效果时间线

| 时间 | 发生什么 |
| --- | --- |
| 打开页面 | 随机显示 10 条吹捧文案中的 1 条 |
| 1 秒后 | 播放欢呼音效，二维码下方出现「天气从未如此明媚」玻璃条，持续 3 秒 |
| 10 秒后（页面还开着） | 玻璃条换成「你这么好看，在犹豫什么」，持续 4 秒 |
| 关闭页面 | 取消还没触发的任务 |

规则：

- 每次打开只触发一次
- 动画在二维码**下方**，不覆盖二维码
- 没有「已打赏」按钮，不要求用户额外点击
- 关掉窗口就取消，避免关窗后突然响

> 注意：微信赞赏码没有支付回调，App 无法真的知道「谁扫码了 / 谁付了钱」。这里的 1 秒 / 10 秒是**打开页面后的定时触发**，不是支付检测。如果你要真实支付回调，需要接微信支付/支付宝的商户 API。

## 2. 10 条吹捧文案

每次打开随机抽一条：

1. 你真好看
2. 今天的你，比昨天更好看
3. 你的品味，真的很在线
4. 你一笑，天气都变好了
5. 你认真生活的样子，很迷人
6. 你值得所有温柔和好运
7. 你一来，整个房间都亮了
8. 你的眼光，从来不会让人失望
9. 你不仅好看，还很有眼光
10. 有你在，平凡的一天也会发光

文案在 `DonationRewardView.compliments` 里，中英双语成对存放。要改文案，直接改数组；要加文案，数组加一项，随机范围会自动跟着变。

## 3. 最小接入

把 `DonationEasterEgg.swift` 拖进你的 macOS SwiftUI / AppKit 工程，然后在一个窗口或 sheet 里显示。

> 如果工程里已经有 `GlassPanel` 或 `CelebrationSound` 同名类型，复制后改个名字即可。

```swift
import AppKit
import SwiftUI

let host = NSHostingController(
    rootView: DonationRewardView(
        qrImage: NSImage(named: "donation-qr"),
        onClose: { NSApp.keyWindow?.close() }
    )
)

let window = NSWindow(contentViewController: host)
window.title = "有你真好"
window.styleMask = [.titled, .closable]
window.isReleasedWhenClosed = false
window.center()
window.makeKeyAndOrderFront(nil)
```

二维码图片放进 `Assets.xcassets` 或 Bundle，名字对上即可。没有图片时会显示一个占位的 `qrcode` 图标。

如果是在 SwiftUI 里用 `.sheet`：

```swift
.sheet(isPresented: $showDonation) {
    DonationRewardView(
        qrImage: NSImage(named: "donation-qr"),
        onClose: { showDonation = false }
    )
}
```

## 4. 可调参数

| 参数 / 常量 | 默认 | 说明 |
| --- | --- | --- |
| `qrSize` | 293 | 二维码边长 |
| `panelWidth` | 400 | 整个页面宽度 |
| `GlassPanel.alpha` | 0.5 | 玻璃条透明度，越小越透 |
| 第一条消息延迟 | 1.0 秒 | `scheduleCelebrationOnce` |
| 第一条消息停留 | 3.0 秒 | `showMessage(..., duration: 3.0)` |
| 第二条消息延迟 | 10.0 秒 | `scheduleNudgeOnce` |
| 第二条消息停留 | 4.0 秒 | `showMessage(..., duration: 4.0)` |
| 音效音量 | 0.4 | `mainMixerNode.outputVolume` |

## 5. 音效是怎么来的

不加载任何 mp3 / wav，直接用 `AVAudioEngine` 合成：

- C5 → E5 → G5 → C6 四个短音，快速上行
- 叠加一个 C 大三和弦，指数衰减
- 整体音量压到 0.4，短促、不吵
- 失败时回退到系统音 `Glass`

这段代码可以单独抽出来，在任何 AppKit macOS App 里调用 `CelebrationSound.play()`。

## 6. 玻璃条

玻璃条用 `NSVisualEffectView`：

```swift
view.material = .popover
view.blendingMode = .behindWindow
view.state = .active
view.alphaValue = 0.5
```

外面套 `RoundedRectangle(cornerRadius: 10)` 裁剪，再加一层 0.18 白描边。
`alpha = 0.5` 比系统默认材质更透；想更透就调到 0.35，想更实就调到 0.7。

## 7. 复刻到其他软件时的注意点

1. **不要阻塞二维码**：把彩蛋放在二维码下方或窗口边缘，不要盖住扫码区域。
2. **不要自动循环播放**：每次打开只播一次，避免用户停留时反复响。
3. **关窗取消任务**：`onDisappear` 里 `cancel()`，否则窗口关了还会响。
4. **音量要低**：0.3–0.5 之间；办公室场景尤其重要。
5. **文案不要带句号**：这是这套 UI 的排版习惯，最后一行也不加句号。
6. **不要假装知道支付结果**：没有支付回调时，明确这是「打开页面后的彩蛋」，不要写成「感谢你的打赏」这类会被误解的文案。
7. **窗口尺寸**：400 × 约 500，二维码 293；如果二维码更大，按比例调整 `panelWidth`。

## 8. 菜单入口（可选）

如果想要一个带表情的菜单入口：

```swift
let item = NSMenuItem(title: "有你真好", action: #selector(openDonation), keyEquivalent: "")
item.target = self
item.attributedTitle = NSAttributedString(string: "👏  有你真好")
menu.addItem(item)
```

或者用 SF Symbol `hands.sparkles.fill` 生成 14×14 的小图标，放进 `NSTextAttachment` 作为 `attributedTitle` 的前缀。
