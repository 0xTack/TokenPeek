## 3. 1.7 做了什么（已发布）

- 启动时不再自动弹主窗口，只驻留菜单栏；`--window` 仍可打开
- 「我的用量」没有数据时保留完整版面：零值 + 空状态卡片（接入来源 / 刷新），面板不再塌缩
- Release 与官网去掉 Windows；`site/tools/publish.mjs` 不再生成 Windows 条目；Windows 包不再上传

## 4. 1.8 做了什么（已发布）

**外观白板修复**
- 现象：跟随系统时，系统切深浅色 / 睡眠唤醒后面板偶尔变白板，只有去设置里重选外观才恢复
- 原因：SwiftUI 的环境色只在启动和手动改设置时算一次
- 修复：`AppearanceModel` 监听系统主题、唤醒、重新激活；毛玻璃层显式跟随 `colorScheme`；打开面板 / 主窗口时重新确认外观
- 已验证：面板打开时切换系统深浅色，能实时跟着变

**英文界面翻译**
- `省` → `saved`（排名行前缀）
- token 单位 `亿 / 万` → `M / B / K`
- `人民币` → `CNY`
- 订阅周期 `周 / 月` → `Wk / Mo`（只在显示层映射，`subscriptions.json` 里仍存中文标签）

**对齐**
- 排名行价格拆成固定列：前缀 11pt（中文）/ 28pt（英文），金额 58pt 右对齐；token 列 46pt，模型名不再被截断

**订阅**
- 请求失败 / 超时的订阅整行隐藏，不再显示 `The request timed out.`
- 全部失败时整个订阅区块隐藏；余额行出现刷新按钮，同时重试余额与订阅

**发布信息**
- 版本 1.8 / Build 9，四个 macOS 资产，官网页头 / 下载区 / 页脚 / 更新日志均为 1.8

## 5. 1.9 做了什么（已发布）

**面板关闭修复**
- 现象：打开面板、操作部分选项（尤其下拉菜单）后，点桌面空白处面板不消失
- 修复：面板显示时挂全局鼠标监听 `startPopoverDismissMonitor()`，点到面板外就 `performClose`；`popoverDidClose` 移除监听；`showPopover` 每次重设 `.transient`，并改成先激活 App 再显示
- 曾试过监听 `didResignActive` 关闭面板，会在后台启动场景误关，已移除

**奶油猫图标**
- 原图白底、无透明通道：按圆角裁掉白边、整体放大 3%，生成透明 1024 图，并打包成 `AppIcon.icns`
- 新增 `AppIconChoice.cat`，设置里排在第一位，默认值改为 `cat`（`AppIconStore.choice` 的兜底值和 `@AppStorage` 默认值都改了）
- 三个打包脚本都会把 `AppIcon-cat.png` 拷进 App
- 官网 `site/assets/icon-tokenpeek.png` 同步换成奶油猫（页头、页脚、works 卡片、favicon）

**发布信息**
- 版本 1.9 / Build 10，四个 macOS 资产；站点页头 / 下载区 / 页脚 / 更新日志均为 1.9
- 发布过程中 GitHub 偶发 `Internal Server Error (500)`，重试 push / release 即可

## 8. 构建与发布

```bash
cd "/Users/xa/Documents/Default Project/DeepSeekCost"

# 编译检查
swiftc -sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk \
  -swift-version 5 -target arm64-apple-macosx14.0 main.swift -o /tmp/check

# 自检
/tmp/check --self-test

# 本机安装
./build.sh

# 打包（自动 1.9 → 1.10、Build 10 → 11）
./package.sh
./package-intel13.sh

# 发布
git push origin main
git tag -f v1.10 && git push -f origin v1.10
gh release create v1.10 dist/TokenPeek-1.10-AppleSilicon.dmg dist/TokenPeek-1.10-AppleSilicon.zip \
  dist/TokenPeek-1.10-Intel.dmg dist/TokenPeek-1.10-Intel.zip \
  --title "TokenPeek 1.10" --notes-file /tmp/notes.md --latest --verify-tag

# 站点
cd site
./publish.sh --version 1.10 --mac-version 1.10 \
  --base "https://github.com/0xTack/TokenPeek/releases/download/v1.10/" \
  --notes "条目 1|条目 2"
```

站点部署：`site/index.html` 的页头胶囊、下载区版本句、页脚、`macos-open.html` 的校验文件名要手动改；然后 rsync `site/`（排除 `downloads/`）到 `/tmp/tp-pages`（gh-pages 克隆）→ commit → push。
