# 自定义来源接入说明（DeepSeek / OpenAI）

适用于 TokenPeek 1.4 及以后。本文写给用户，也写给 AI：把本文和厂商 API 文档一起发给 AI，AI 就可以按统一格式生成接入脚本。

---

## 1. 先选接入方式

| 方式 | 适合 | 入口 |
| --- | --- | --- |
| 官方账号（内置） | DeepSeek 官方账户，按 API Key 看用量、余额、总花费 | 「我的用量」→ 官方账号；「管理账号与来源」里添加 |
| 本地来源（通用） | OpenAI、其他厂商、本地工具、自己写的统计脚本 | 「管理账号与来源」→ 本地来源 → 添加来源 |

非 DeepSeek 的厂商，统一走「本地来源」。App 不直接保存厂商密钥，密钥由你的脚本从环境变量或本机配置读取。

---

## 2. 本地来源的工作方式

### 2.1 文件位置

```text
~/Library/Application Support/DeepSeekCost/sources/
```

目录里每个 `.jsonl` 文件就是一个来源，文件名就是来源名。App 启动时会自动扫描，不需要改 App。

也可以给来源配置一条命令。点右上角刷新时，App 会：

1. 运行命令（`/bin/zsh -lc`，20 秒超时）；
2. 把命令输出写到同名 `.jsonl`，或直接读取命令写入的文件；
3. 重新解析并显示。

命令可以拿到这些环境变量：

```text
DS_SOURCE_FILE   目标 .jsonl 的绝对路径
DS_SOURCE_NAME   来源名称
DS_SOURCE_ID     来源 ID
```

**推荐做法**：脚本直接写入 `$DS_SOURCE_FILE`，不要依赖当前目录，所有路径写绝对路径。
**也可以**：只向 stdout 输出 JSONL。只有 stdout 以 `{` 开头时，App 才会把它当作数据；脚本打印的日志不会覆盖数据文件。

### 2.2 重要规则

- **每次运行都要重写整个文件**，不要追加。App 每次读取整个文件，追加会导致重复计费。
- 时间统一用 ISO8601，最好带时区，例如 `2026-11-01T12:00:00+08:00`。
- App 按北京时间自然日分「今日 / 近 7 天 / 本月 / 全部」。
- 金额统一用**人民币**。美元账单请按脚本里的固定汇率换算成 CNY，再写入 `cost`。
- 不要把 API Key、Cookie、Token 写进 JSONL、日志或脚本注释。

---

## 3. JSONL 格式

每行一个 JSON：

```json
{"app":"OpenAI","time":"2026-11-01T12:00:00+08:00","model":"gpt-4o","hit":1200,"miss":3400,"output":800,"cost":0.42}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `app` | 是 | 显示名称，例如 `OpenAI`、`Claude Code` |
| `time` | 是 | `ISO8601`，或 `yyyy-MM-dd HH:mm:ss`（北京时间） |
| `model` | 否 | 模型名；不填按 `deepseek-flash` 处理 |
| `hit` | 否 | 缓存命中输入 tokens；没有就填 0 |
| `miss` | 否 | 未命中输入 tokens；只有总输入时全部填这里 |
| `output` | 否 | 输出 tokens |
| `cost` | 否 | 人民币金额。**非 DeepSeek 来源必须填**，否则会按 DeepSeek 价格估算，金额会错 |
| `timestamp` | 否 | Unix 秒或毫秒，优先于 `time` |

`model` 里带 `pro` 的按 Pro 档处理，其余按 Flash 档；只在没有 `cost`、需要 App 代算 DeepSeek 价格时才有意义。

## 4. DeepSeek

### 4.1 官方账户（推荐，无需脚本）

在「管理账号与来源」里添加官方账号，用网页登录获取 Token。Token 以 `userToken` 为准，不是 `sk-` API Key。

App 读取：

```text
GET https://platform.deepseek.com/api/v0/usage/by_api_key/amount
GET https://platform.deepseek.com/api/v0/usage/by_api_key/cost
GET https://platform.deepseek.com/api/v0/users/get_user_summary
```

总花费来自 `get_user_summary` 的 `biz_data.total_costs`。官方接口单次最多约 31 天，所以「全部」实际是最近 30 天。

**注意**：官方 Token 只存在本机：

```text
~/Library/Application Support/DeepSeekCost/official-accounts.json
```

权限 600，不要复制、打印或发给 AI。

### 4.2 DeepSeek 走本地来源

如果你想自己统计 DeepSeek 的本地调用，可以写：

```json
{"app":"DeepSeek 本地","time":"2026-11-01 12:00:00","model":"deepseek-flash","hit":10000,"miss":20000,"output":3000}
```

不填 `cost` 时，App 会按当前时段（高峰/空闲）的 DeepSeek 官方价自动计算。模型名带 `pro` 按 Pro 价，否则按 Flash 价。

## 5. OpenAI

OpenAI 的用量接口需要 **Admin Key**（组织管理员密钥），普通项目 Key 不能读组织用量。

```text
OPENAI_ADMIN_KEY=sk-admin-...
```

### 5.1 用量接口

```bash
curl -s "https://api.openai.com/v1/organization/usage/completions?start_time=1761955200&end_time=1764547200&bucket_width=1d&group_by[]=model&limit=31" \
  -H "Authorization: Bearer $OPENAI_ADMIN_KEY"
```

返回结构（简化）：

```json
{
  "data": [
    {
      "start_time": 1761955200,
      "end_time": 1762041600,
      "results": [
        {
          "input_tokens": 4600,
          "input_cached_tokens": 1200,
          "output_tokens": 800,
          "num_model_requests": 12,
          "model": "gpt-4o"
        }
      ]
    }
  ],
  "has_more": false,
  "next_page": null
}
```

字段对应：

```text
hit    = input_cached_tokens
miss   = input_tokens - input_cached_tokens
output = output_tokens
time   = start_time（Unix 秒，转成 ISO8601）
model  = model
```

`input_tokens` 通常已包含缓存命中部分，所以 `miss` 要减去 `input_cached_tokens`；如果你的账户返回结构不同，以实际返回为准。

### 5.2 金额接口

```bash
curl -s "https://api.openai.com/v1/organization/costs?start_time=1761955200&end_time=1764547200&bucket_width=1d&limit=31" \
  -H "Authorization: Bearer $OPENAI_ADMIN_KEY"
```

返回的金额在 `data[].results[].amount`：

```json
{"value": 1.23, "currency": "usd"}
```

金额接口通常只给每天/每个 line item 的总额，不一定按模型拆分。可以：

- 按当天各模型的 tokens 占比，把金额分摊到每条记录；
- 或每天只写一条汇总记录（`model` 写 `openai-total`），接受模型排行不细。

### 5.3 换算成人民币

App 统一按人民币显示。脚本里用一个可配置汇率，例如：

```text
USD_CNY=7.20
```

`cost = amount.value * USD_CNY`。请把汇率写进脚本，并在输出里保留一位小数即可；不要依赖 App 换算。

### 5.4 一个可直接改的 Python 骨架

```python
#!/usr/bin/env python3
import json, os, time, urllib.parse, urllib.request
from datetime import datetime, timedelta, timezone

KEY = os.environ["OPENAI_ADMIN_KEY"]
OUT = os.environ.get("DS_SOURCE_FILE", os.path.expanduser(
    "~/Library/Application Support/DeepSeekCost/sources/openai.jsonl"))
USD_CNY = float(os.environ.get("USD_CNY", "7.20"))
DAYS = int(os.environ.get("OPENAI_USAGE_DAYS", "30"))

def get(path, params):
    url = "https://api.openai.com/v1/" + path + "?" + urllib.parse.urlencode(params, doseq=True)
    req = urllib.request.Request(url, headers={"Authorization": "Bearer " + KEY})
    with urllib.request.urlopen(req, timeout=30) as r:
        return json.loads(r.read())

end = int(time.time())
start = int((datetime.now(timezone.utc) - timedelta(days=DAYS)).timestamp())

# 1) 用量
usage = []
params = {
    "start_time": start, "end_time": end, "bucket_width": "1d",
    "group_by[]": ["model"], "limit": 31,
}
while True:
    page = get("organization/usage/completions", params)
    usage += page.get("data", [])
    if not page.get("has_more"):
        break
    params["page"] = page["next_page"]

# 2) 金额（按天）
costs = {}
params = {"start_time": start, "end_time": end, "bucket_width": "1d", "limit": 31}
while True:
    page = get("organization/costs", params)
    for bucket in page.get("data", []):
        day = bucket["start_time"]
        for item in bucket.get("results", []):
            amount = float(item.get("amount", {}).get("value", 0))
            costs[day] = costs.get(day, 0.0) + amount
    if not page.get("has_more"):
        break
    params["page"] = page["next_page"]

# 3) 按天分配金额，输出 JSONL
lines = []
for bucket in usage:
    day = bucket["start_time"]
    results = bucket.get("results", [])
    total_tokens = sum(
        (r.get("input_tokens", 0) + r.get("output_tokens", 0)) for r in results
    ) or 1
    for r in results:
        cached = r.get("input_cached_tokens", 0)
        input_tokens = r.get("input_tokens", 0)
        output_tokens = r.get("output_tokens", 0)
        share = (input_tokens + output_tokens) / total_tokens
        cost_cny = costs.get(day, 0.0) * share * USD_CNY
        dt = datetime.fromtimestamp(day, tz=timezone.utc).astimezone(
            timezone(timedelta(hours=8))
        )
        lines.append(json.dumps({
            "app": "OpenAI",
            "time": dt.isoformat(),
            "model": r.get("model") or "openai",
            "hit": cached,
            "miss": max(0, input_tokens - cached),
            "output": output_tokens,
            "cost": round(cost_cny, 6),
        }, ensure_ascii=False))

os.makedirs(os.path.dirname(OUT), exist_ok=True)
with open(OUT, "w", encoding="utf-8") as f:
    f.write("\n".join(lines) + ("\n" if lines else ""))
print(f"{len(lines)} records -> {OUT}")
```

这个骨架只覆盖最近 N 天（OpenAI 单次最多约 31 天）。要统计全部历史，把 `start` 往前推，按月循环请求，最后统一写入同一个文件。注意分页参数以实际 API 文档为准。

## 6. 在 App 里添加

1. 「管理账号与来源」→「＋ 添加来源」；
2. 名称填 `OpenAI`；
3. 命令填脚本路径并带参数，例如：

   ```bash
   /usr/bin/python3 "$HOME/Library/Application Support/DeepSeekCost/sources/openai_usage.py"
   ```

4. 保存后点「运行」；或直接点面板右上角刷新；
5. 在「我的用量」的数据源菜单里选择「本地 · OpenAI」。

如果脚本只生成文件、没有命令，也可以把 `openai.jsonl` 直接放进 `sources/`，App 会自动发现。

## 7. 让 AI 按本文接入新厂商

把下面这段连同厂商 API 文档一起发给 AI：

```text
你在帮我给 macOS 上的「TokenPeek」写一个本地用量接入脚本。

先读这份说明：
[粘贴本文，或说明 “按 TokenPeek 自定义来源规范”]

目标厂商：<厂商名>
API 文档：<链接或粘贴返回示例>
本机可用凭据：<环境变量名，不要把真实密钥写进对话>

请直接完成：
1. 找到该厂商的用量/账单接口，说明需要什么权限；
2. 写一个可重复运行的脚本，输出到
   ~/Library/Application Support/DeepSeekCost/sources/<id>.jsonl；
3. 每行严格符合本文的 JSONL 格式；非 DeepSeek 必须写 cost（人民币）；
4. 每次运行重写整个文件，不追加；
5. 不要把密钥写进脚本、日志或输出；
6. 先运行一次，报告记录条数、总 tokens、总金额和文件路径；
7. 如果接口拿不到用量，直接说明，不要编造数据。
```

## 8. 常见问题

**Q：为什么我的 OpenAI 金额显示成 ¥ 但数字很小？**
A：`cost` 被当成了人民币。请先在脚本里把 USD 换算成 CNY。

**Q：为什么总花费比预期多？**
A：脚本追加写入导致重复。每次运行要重写文件。

**Q：为什么刷新后没有变化？**
A：检查命令是否在 20 秒内结束、是否写入 `$DS_SOURCE_FILE`，以及文件里每行是否是合法 JSON。

**Q：DeepSeek 官方账号能自动带出昵称吗？**
A：官方接口不返回昵称/邮箱。账号名是本地名称，可以在「管理账号与来源」里改成「主账号」「公司账号」等。

**Q：OpenAI 普通 API Key 可以吗？**
A：读组织用量需要 Admin Key；普通项目 Key 会返回 401/403。
