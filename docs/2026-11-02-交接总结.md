## 4. 构建 / 打包 / 发布命令

```bash
cd "/Users/xa/Documents/Default Project/DeepSeekCost"

# 编译检查
swiftc -sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk \
  -O -swift-version 5 -target arm64-apple-macosx14.0 \
  main.swift -o /tmp/check

# 自检
/tmp/check --self-test

# 本机安装
./build.sh

# 打 Apple Silicon 包（不自动升版本）
SKIP_VERSION_BUMP=1 ./package.sh

# 打 Intel 包（沿用 Info.plist 版本）
./package-intel13.sh

# 创建 Release（示例）
gh release create v1.5 \
  dist/TokenPeek-1.5-AppleSilicon.dmg \
  dist/TokenPeek-1.5-AppleSilicon.zip \
  dist/TokenPeek-1.5-Intel.dmg \
  dist/TokenPeek-1.5-Intel.zip \
  --title "TokenPeek 1.5" --notes-file /tmp/notes-1.5.md

# 更新站点版本数据
cd site
./publish.sh --version 1.5 --mac-version 1.5 --windows-version 1.3 \
  --base "https://github.com/0xTack/TokenPeek/releases/download/v1.5/" \
  --notes "液态玻璃面板|状态圆环配色|多账号总花费|趋势图简化|价格识别与 iCloud 备份"

# 部署 gh-pages（当前工作流）
rsync -a site/index.html site/works.html site/macos-open.html site/.nojekyll /tmp/tp-pages/
rsync -a site/assets/ /tmp/tp-pages/assets/
cd /tmp/tp-pages
git add -A
git commit -m "..."
git push origin gh-pages
```

注意：

- `publish.sh --no-copy` 要求文件已经在 `site/downloads/` 里；否则会报 ENOENT。正常模式会从 `../dist` 复制。
- `site/tools/publish.mjs` 的 mac `sourceStem` / `releaseStem` 已改成 `TokenPeek-${version}-...`。
- Pages 源分支是 `gh-pages`，不是 `main`。
- 不要上传 `site/downloads/`（Windows 包 153 MB，Pages 单文件限制 100 MB）。

## 8. 软件更新方式（现状与建议）

### 现状

- 启动时静默检查 GitHub Releases，24 小时内只查一次
- 右键菜单可手动检查
- 发现新版本 → 弹窗 → 打开 Release 页面 → 用户自己下载安装
- 不做自动下载、不自动安装

### 建议

**短期**：保持现状。发版时递增 `Info.plist` 版本、上传 Release、更新站点即可。

**中期**：接 Sparkle 2

- `appcast.xml` + EdDSA 签名 + DMG/ZIP
- 支持自动下载、退出时安装、增量更新、稳定/测试通道
- 需要 `SUFeedURL`、`SUPublicEDKey`，发版时用 `generate_appcast`
- ad-hoc 签名也能用（Sparkle 自己验 EdDSA），但用户首次打开仍可能遇到 Gatekeeper 提示
- 有 Developer ID + 公证后体验最好

**版本规则**

- marketing version：1.5
- build number：6，每次发版必须递增（Sparkle 比较 CFBundleVersion）

**Windows**

- 用 `electron-updater` 或继续手动更新，和 macOS 分开处理
