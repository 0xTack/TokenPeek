## 4. 1.8 做了什么（已发布）

**外观白板修复**
- 现象：跟随系统时，系统切深浅色 / 睡眠唤醒后面板偶尔变白板，只有去设置里重选外观才恢复
- 原因：SwiftUI 的环境色只在启动和手动改设置时算一次
- 修复：`AppearanceModel` 监听系统主题、唤醒、重新激活；毛玻璃层显式跟随 `colorScheme`；打开面板 / 主窗口时重新确认外观
- 已验证：面板打开时切换系统深浅色，能实时跟着变

**英文界面翻译**
- `省` → `saved`（排名行前缀）
- token 单位 `亿 / 万` → `M / B / K`
- `人民币` → `CNY`
- 订阅周期 `周 / 月` → `Wk / Mo`（只在显示层映射，`subscriptions.json` 里仍存中文标签）

**对齐**
- 排名行价格拆成固定列：前缀 11pt（中文）/ 28pt（英文），金额 58pt 右对齐；token 列 46pt，模型名不再被截断

**订阅**
- 请求失败 / 超时的订阅整行隐藏，不再显示 `The request timed out.`
- 全部失败时整个订阅区块隐藏；余额行出现刷新按钮，同时重试余额与订阅

**发布信息**
- 版本 1.8 / Build 9，四个 macOS 资产，官网页头 / 下载区 / 页脚 / 更新日志均为 1.8

## 5. 未发布的本地改动（下一个会话第一件事）

**现象**：打开面板、操作部分选项（尤其下拉菜单）后，点桌面空白处面板不消失。

**修复**（`main.swift`，工作区 +28 行未提交）：
- 面板显示时挂全局鼠标监听 `startPopoverDismissMonitor()`：点到面板外（桌面 / 其他 App）就 `performClose`
- `popoverDidClose` 里移除监听
- `showPopover` 每次重设 `.transient`，并改成先 `NSApp.activate` 再显示
- 曾试过监听 `didResignActive` 关闭面板，会在后台启动场景误关，已移除

**状态**：用户已在本机验证有效（2026-11-04）。但**没有提交、没有打包、没有上传**。

**下一步**：提交 → 按 1.9 发版（`package.sh` 自动 1.8→1.9、Build 9→10）→ Intel 包 → Release → 站点。

## 8. 构建与发布

```bash
cd "/Users/xa/Documents/Default Project/DeepSeekCost"

# 编译检查
swiftc -sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk \
  -swift-version 5 -target arm64-apple-macosx14.0 main.swift -o /tmp/check

# 自检
/tmp/check --self-test

# 本机安装
./build.sh

# 打包（自动 1.8 → 1.9、Build 9 → 10）
./package.sh
./package-intel13.sh

# 发布
git push origin main
git tag -f v1.9 && git push -f origin v1.9
gh release create v1.9 dist/TokenPeek-1.9-AppleSilicon.dmg dist/TokenPeek-1.9-AppleSilicon.zip \
  dist/TokenPeek-1.9-Intel.dmg dist/TokenPeek-1.9-Intel.zip \
  --title "TokenPeek 1.9" --notes-file /tmp/notes.md --latest --verify-tag

# 站点
cd site
./publish.sh --version 1.9 --mac-version 1.9 \
  --base "https://github.com/0xTack/TokenPeek/releases/download/v1.9/" \
  --notes "条目 1|条目 2"
```

站点部署：`site/index.html` 的页头胶囊、下载区版本句、页脚、`macos-open.html` 的校验文件名要手动改；然后 rsync `site/`（排除 `downloads/`）到 `/tmp/tp-pages`（gh-pages 克隆）→ commit → push。
