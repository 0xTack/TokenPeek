# 打赏功能说明（TokenPeek「有你真好」）

> 用途：把这套打赏页复刻到另一个软件时，照着本文实现即可。  
> 代码位置：`main.swift` 里的 `DonationView`、`DonationQRCode`、`CelebrationSound`、`showDonation`、`StatusMenuView`。

## 1. 功能定位

- 免费软件的自愿赞赏，**不换取任何功能或服务，不支持退款**
- 不在启动时弹窗、不挡主流程；只有一个菜单入口
- 双渠道：
  - 主入口：爱发电按钮 `https://afdian.com/a/tack123`
  - 次入口：微信赞赏码（可选，图片不存在时自动隐藏）
- 不接支付回调，**不假装知道谁付了钱**

## 2. 入口

- 菜单栏右键菜单：`👏 有你真好`（在「检查更新」下方，上方一条分隔线，下方分隔线后是「退出」）
- CLI：`--donation`（启动后自动打开赞赏窗口，用于调试）
- 窗口标题：`有你真好` / `So glad to have you`

## 3. 窗口行为

- 独立窗口（`titled + closable`），不随关闭释放，重复打开复用同一个
- 打开流程：先 `layoutSubtreeIfNeeded` → `setContentSize(fittingSize)` → 再居中
  - 顺序不能反，否则窗口会以旧尺寸居中后向右下长，偏 10–15pt
- 居中在鼠标所在屏幕的 `visibleFrame`，并限制在可视区域内
- 不阻塞主界面；Esc 或「关闭」按钮关闭

## 4. 界面结构（当前参数）

| 元素 | 参数 |
|---|---|
| 窗口宽 | 340pt |
| 内边距 | 18pt |
| 纵向间距 | 10pt |
| 顶部吹捧文案 | 14pt medium，最多 300pt 宽 |
| 爱发电按钮 | 紫色胶囊，白字 12pt semibold，内边距 20 / 9 |
| 分隔文案 | `或 微信扫码` / `or scan WeChat`，9pt |
| 二维码 | 120 × 120pt，圆角 8pt；运行时按深色内容自动裁正居中（金色徽章不参与） |
| 消息条预留 | 26pt（默认空，彩蛋时显示玻璃条） |
| 声明 | 9pt secondary，居中 |
| 关闭按钮 | 默认按钮，Esc 快捷键 |

顺序（从上到下）：

1. 随机吹捧文案
2. `去爱发电支持` 按钮
3. `或 微信扫码` 分隔线（仅当二维码存在）
4. 微信赞赏码（仅当图片存在）
5. 26pt 消息条（默认空；彩蛋时出现）
6. 声明：`自愿赞赏 · 不换取任何功能或服务 · 不支持退款`
7. `关闭`

注意：二维码下面**不要**再放「微信扫码赞赏」文字（已按用户要求删除）。

## 6. 彩蛋时序

打开窗口后：

- `0s`：随机显示一条吹捧文案
- `1s`：播放合成欢呼音效，并显示玻璃条「天气从未如此明媚 / The weather has never been so bright」持续 **3 秒**
- `10s` 仍未关闭：显示「你这么好看，在犹豫什么 / You look so great. What are you waiting for?」持续 **4 秒**
- 每个彩蛋每次打开只触发一次
- 关闭窗口时取消未触发的任务
- 消息显示用淡入淡出（0.25s 进 / 0.3s 出）

## 7. 音效

- 用 `AVAudioEngine` 实时合成，不需要音频资源
- 内容：C5–E5–G5–C6 琶音（0 / 0.1 / 0.2 / 0.3s）+ 0.42s 起的三音和弦，总长 1.6s
- 主音量 0.4，单样本限制在 ±0.35
- 启动失败时回退 `NSSound(named: "Glass")`
- 2 秒后自动停止并释放

## 8. 资源与打包

- 二维码文件：`donation-qr.png`（620 × 620）
- 默认**不提交仓库**，本机打包时注入
- macOS：
  - `build.sh` / `package.sh` / `package-intel13.sh` 复制到 `Contents/Resources/`
  - 找不到文件时二维码整块隐藏，只留爱发电按钮
- Windows：
  - `windows/build-windows.sh` 复制到 `windows/assets/`
- 爱发电链接目前硬编码：`https://afdian.com/a/tack123`

## 9. 代码结构（SwiftUI）

- `DonationView`：界面、随机文案、彩蛋状态机
- `DonationQRCode`：从 bundle 读图；`hasImage` 决定是否显示二维码
- `CelebrationSound`：合成欢呼音效
- `GlassBackground`：`NSVisualEffectView(.popover)` 半透明玻璃条
- `showDonation()`：创建/复用窗口、定尺寸、居中、激活
- `StatusMenuView`：右键菜单入口

## 10. 移植到其他技术栈（Electron / 其他）

- 入口放在「关于 / 设置」或菜单里，**不要启动弹窗**
- 打开系统浏览器：`https://afdian.com/a/tack123`
- 二维码可选：展示前先检查资源是否存在，缺失就隐藏整块
- 文案和声明照抄，不要写「购买 / 会员 / 解锁」
- 彩蛋用定时器；窗口关闭时清理所有定时器
- 深色模式要单独适配文字和玻璃背景
- 建议尺寸：宽 340，二维码 120，声明 9pt
- 不要做「已打赏」状态，也不要根据支付结果写感谢文案

## 11. 合规注意

- 文案必须体现：自愿、不换功能/服务、不退款
- 爱发电方案目前按月计费，页面会显示 `/月`；文案里不必强调，但用户实际是按月赞助
- 微信赞赏码：快，但有风控/限额/海外不可用；不要用于经营收款
- 赞赏属于个人所得，金额大时注意申报
- 不要在 App 内假装知道支付结果
