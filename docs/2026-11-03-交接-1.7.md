### 2.3 通用订阅监控（1.6 核心功能）

**能力**

- 任意返回 JSON 的 GET 接口都能接
- 认证：无 / Bearer / 自定义 Header
- 指标类型：已用 % / 剩余 % / 剩余÷总量
- 一个订阅可含多个指标（如 5h / 周 / 月）
- 字段路径点分（`usage.rolling.percent`），数组下标（`data.0.left`）
- 「识别字段」按钮：请求一次，把数字字段列成下拉菜单直接选
- 重置时间路径可选，目前面板不显示倒计时（已按要求删掉）
- 面板样式两种：**胶囊 / 柱状图**，设置里切换
- 口径切换：**剩余 / 已使用**，颜色规则反转（剩余 ≤30% 橙、≤10% 红；已使用 ≥70% 橙、≥90% 红）
- 存储：`~/Library/Application Support/DeepSeekCost/subscriptions.json`（600）
- 刷新节流：60 秒

**面板**

- 订阅行与余额行合并成一块，中间无分割线
- 整个区块只有一个刷新按钮，同时刷新余额与订阅
- 「充值」改为 hover 浮层（overlay，不改变行高）
- 订阅区块有最小高度，数据到达时面板不上下伸缩

**设置**

- 「订阅与花费」合并订阅和手动花费
- 删除：用量显示切换、更新日志 / 反馈入口
- 「我的用量」固定逐行数字显示

**修复**

- 显示切换不生效：`@AppStorage` 跨窗口刷新不可靠，改为共享 `SubscriptionSettings`（ObservableObject）

## 3. 待办（下一个会话第一件事）

**启动时不再自动弹出主窗口**（用户已提出，尚未实现）

- 位置：`main.swift` 第 8890–8897 行
- 现状：无参数启动 0.5 秒后调用 `showMainWindow()`；只有带 `--background` 才不弹
- 期望：默认只驻留菜单栏；`--window` 参数仍能打开；右键菜单「打开主窗口」保持可用
- 改法：删掉 `else if !ProcessInfo.processInfo.arguments.contains("--background")` 分支，只保留 `--window` 分支

```swift
// 改前
if ProcessInfo.processInfo.arguments.contains("--window") {
    DispatchQueue.main.asyncAfter(deadline: .now() + 0.6) { self.showMainWindow() }
} else if !ProcessInfo.processInfo.arguments.contains("--background") {
    DispatchQueue.main.asyncAfter(deadline: .now() + 0.5) { self.showMainWindow() }
}

// 改后
if ProcessInfo.processInfo.arguments.contains("--window") {
    DispatchQueue.main.asyncAfter(deadline: .now() + 0.6) { self.showMainWindow() }
}
```

注意：`build.sh` 与开机自启已经用 `--background`，改后行为一致，不会影响自启。
